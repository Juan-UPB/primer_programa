# 💻 Taller 2 - Hola Mundo en Java

## 📌 Descripción del proyecto
Este proyecto consiste en la creación de un programa básico en Java llamado *HolaMundo*, desarrollado como parte del segundo taller del curso.

El objetivo es comprender la estructura de un programa en Java, aprender el uso de Git y GitHub para el control de versiones y fortalecer el trabajo colaborativo en equipo.

---

## ▶️ Instrucciones para ejecutar el programa

1. Clonar el repositorio:
   bash
   git clone https://github.com/Juan-UPB/primer_programa.git
   

2. Abrir el proyecto en *Visual Studio Code* o cualquier IDE compatible con Java.

3. Compilar el programa:
   bash
   javac HolaMundo.java
   

4. Ejecutar el programa:
   bash
   java HolaMundo
